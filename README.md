# Realme GT2 Pro device tree

RMX3301 device configuration, overlays and extraction scripts
for **LineageOS 23.2 / Android 16**. Package-23b uses this source.
Both Package-23b and the Android 17 release use kernel **5.10.246**.

## Build and download

- [ROM downloads and installation](https://github.com/wjdob/lineageos-realmegt2pro/tree/lineage-23.2)
- [Source versions and kernel archive](https://github.com/wjdob/lineageos-realmegt2pro/blob/lineage-23.2/SOURCES.md)
- [Build prerequisites and source commands](https://github.com/wjdob/lineageos-realmegt2pro-manifests/tree/lineage-23.2)
- [Optional Camera, Photos and Clock](https://github.com/wjdob/realmegt2pro-oem-apps)

Use the matching manifest to download the full source tree. Builds also require
matching stock files and your own signing keys. `SOURCE_BASELINE.json` lists the
upstream version and the release's expected file hashes.
