# Realme GT2 Pro device tree

LineageOS 23.2 source used by the RMX3301 Package-23b release.
Upstream work comes from [pjgowtham](https://github.com/pjgowtham/android_device_realme_ferrari); its Git history is retained.
Project commits import the published device-integration patches and templates.
`SOURCE_BASELINE.json` records their hashes and the exact upstream revision.

[Downloads, install guide and user issues](https://github.com/wjdob/lineageos-realmegt2pro).
[Pinned manifests and build notes](https://github.com/wjdob/lineageos-realmegt2pro-manifests/tree/lineage-23.2).
Use the complete source graph and remaining patches there when building.
Proprietary firmware inputs and signing keys are separate prerequisites.

Camera, Photos and Clock are optional and maintained in
[realmegt2pro-oem-apps](https://github.com/wjdob/realmegt2pro-oem-apps).
The source reorganization changes no released binary or runtime qualification.
Original file licenses and copyright notices remain in place.
